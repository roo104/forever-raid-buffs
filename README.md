# Forever Raid Buffs

A raid planner for World of Warcraft: Forever. Drag classes into groups to see which buffs each group has and which are missing. Pure melee groups only list melee buffs, and caster groups only list caster buffs. It also covers raid-wide buffs, paladin blessings, boss debuffs and resistances.

Buff rules follow the WoW Forever beta development notes of October 15, 2026.

Live site: https://roo104.github.io/forever-raid-buffs/

It's a single static `index.html` with no build step.
